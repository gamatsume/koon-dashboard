# Welcome to your Vault Dashboard

This is a sample [Obsidian](https://obsidian.md) vault used to demo the dashboard app.

Every `.md` file in this `vault/` folder is picked up automatically and rendered
on the dashboard, just like it would be in Obsidian itself.

## What's inside

- [[Project Ideas]] — a running list of side project ideas
- [[Reading List]] — books and articles, with a checklist
- [[Daily Notes/2026-07-27]] — an example daily note

## How it works

The Next.js app reads every Markdown file under `vault/`, parses the
frontmatter (title, tags, date), and renders a card-based dashboard on the
home page. Click a note to see the full rendered Markdown, including
tables, checklists, and code blocks.
